Тема 2

Использование электронных таблиц при моделировании математических задач

Лабораторные работы

По теме 2 выполнены две лабораторные работы в программе MS Excel. Все задания каждой работы выполнены в одном файле на отдельных листах. На каждом листе добавлен верхний колонтитул с ФИО и номером подгруппы, установлен единый стиль форматирования, листы переименованы в соответствии с выполняемыми заданиями.

Файл «ЛР графики.xlsx»

В файле находится выполнение лабораторной работы по построению графиков функций и графиков поверхностей. Построены графики линейной функции y = kx + b, ряда функций с использованием встроенных функций Excel (показательной, корня, модуля, дробной, логарифмической), а также график поверхности — гиперболического параболоида.

Использованы функции Excel: POWER (СТЕПЕНЬ), SQRT (КОРЕНЬ), ABS (модуль), LN (натуральный логарифм), а также диаграммы типа «Точечная» и «Поверхность».

Открыть файл «ЛР графики.xlsx»

Файл «ЛР матрицы.xlsx»

В файле находится выполнение лабораторной работы по решению задач с матрицами. Выполнены сложение и вычитание матриц, умножение матрицы на число, получение единичной матрицы, умножение матриц, транспонирование матрицы, вычисление определителя и нахождение обратной матрицы.

Использованы функции Excel: MMULT (МУМНОЖ), TRANSPOSE (ТРАНСП), MDETERM (МОПРЕД), MINVERSE (МОБР), а также формулы для построения единичной матрицы.

Открыть файл «ЛР матрицы.xlsx»
